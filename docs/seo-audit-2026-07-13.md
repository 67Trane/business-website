# SEO Audit — mehmet-deliaci.net (2026-07-13)

**SEO Health Score: 55/100** · Business type: solo freelance web-dev portfolio (DE, Weißenburg i. B.), Angular 21 SSR + Express, Cloudflare-fronted.

## Root cause behind most findings

The site is architecturally a single page pretending to be a multi-page site. `src/app/app.routes.ts` defines only `/`, `/impressum`, `/datenschutz`; everything else hits `{ path: '**', redirectTo: '' }`, which is also prerendered — so **every guessed URL (`/leistungen`, `/kontakt`, `/randomjunk`) returns HTTP 200 with byte-identical homepage content**. Canonical tags mask the duplicate-content risk, but it blocks: real 404s, a correct sitemap, per-topic keyword targeting, and focused AI/Google citations.

## Critical

1. **Impressum VAT ID reads "folgt" (TBD)** — unfinished legal disclosure live in production. `src/app/pages/legal/imprint.ts`. Needs real USt-IdNr. or correct Kleinunternehmer wording (owner input required).
2. **~6,000px blank/dead space on mobile** between hero and next section (mobile full page 10,903px vs desktop 6,716px; blank white → lavender → navy bands). Likely non-reflowing grid/flex or stuck scroll-reveal at 375px width.
3. **No real 404s** — any path returns 200 + homepage. Fix: real NotFound route returning HTTP 404 (Express layer or `@angular/ssr` not-found handling), remove blanket wildcard prerender.
4. **Zero security headers** — HSTS, CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy all absent. Fix in `src/server.ts` (helmet-style middleware) or Cloudflare Transform Rules.
5. **Cloudflare blocks GPTBot + ClaudeBot at the edge** (managed robots.txt), contradicting the permissive `public/robots.txt` in this repo. Dashboard-only fix: Cloudflare → Bots → AI Crawl Control → allow GPTBot, ClaudeBot (keeping CCBot/Bytespider/etc. blocked is fine).

## High

7. No `www` → apex 301 (both hosts serve identical 200s). Cloudflare redirect rule.
8. `llms.txt` doesn't exist but 200s with homepage HTML (wildcard symptom). Add real `public/llms.txt` (+ optionally `llms-full.txt`); `express.static` serves it once present.
9. No phone number anywhere (on-site or schema). Add to footer/contact + `telephone` in JSON-LD (owner input required).
10. Zero third-party trust signals — no testimonials/reviews/ratings anywhere. Largest single E-E-A-T lever (owner input required: 2–3 client quotes).
11. "Freelance"/"Freelancer" appears nowhere on the page — competitors lead with it in title tags. Add to `<title>`, meta description, H1/H2 copy (`src/app/data/i18n.data.ts`, `home.ts`).
